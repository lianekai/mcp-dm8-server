## [1.0.0] - 2025-11-08

### ✨ 新增功能
- 初始版本发布
- 实现 MCP 协议支持
- 提供三个核心工具：
  - `list_tables`: 列出数据库表
  - `execute_query`: 执行只读 SQL 查询
  - `describe_table`: 查询表结构

### 🔒 安全特性
- 基础的 SQL 注入防护
- 只读查询验证
- 标识符规范化

### 📦 依赖
- @modelcontextprotocol/sdk: ^1.21.0
- dmdb: ^1.0.40189
- dotenv: ^17.2.3
- zod: ^3.25.76

## 修改记录格式说明

### 变更类型
- `✨ 新增功能` - 新增的功能特性
- `🐛 修复 Bug` - Bug 修复
- `⚡ 性能优化` - 性能改进
- `🔒 安全性改进` - 安全相关的改进
- `💥 破坏性变更` - 不兼容的 API 变更
- `📝 文档改进` - 文档更新
- `🎨 代码优化` - 代码重构（不影响功能）
- `🧪 测试` - 测试相关的改动
- `🔧 配置` - 配置文件的修改
- `📦 依赖` - 依赖包的更新

### 示例条目

```markdown
## [版本号] - YYYY-MM-DD

### ✨ 新增功能
- 添加了 XXX 功能 (#PR编号)
- 支持 YYY 特性

### 🐛 修复 Bug
- 修复了 XXX 问题 (#Issue编号)
- 解决了 YYY 错误

### 🔒 安全性改进
- 修复了 SQL 注入漏洞
- 加强了输入验证

### 💥 破坏性变更
- 修改了 API 接口 XXX
- 删除了已废弃的 YYY 方法
```

## 维护指南

### 如何更新此文档

1. **每次提交前**：更新 `[未发布]` 部分
2. **发布新版本时**：
   - 将 `[未发布]` 的内容移到新版本号下
   - 添加发布日期
   - 创建新的 `[未发布]` 部分

3. **版本号规则**（语义化版本）：
   - **主版本号（Major）**：不兼容的 API 变更
   - **次版本号（Minor）**：向下兼容的新功能
   - **修订号（Patch）**：向下兼容的 Bug 修复

### 提交信息格式

```bash
# 格式
<type>(<scope>): <subject>

# 示例
feat(tools): 添加事务支持
fix(validation): 修复 SQL 注入漏洞
docs(readme): 更新安装说明
```
